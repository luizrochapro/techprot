================================================================================
ESPECIFICAÇÃO ARQUITETURAL E GUIA DE IMPLEMENTAÇÃO: DIAGRAMA UNIFILAR INTERATIVO (CAD)
Objetivo: Especificação técnica completa e reprodutível para recriar o subsistema de CAD unifilar elétrico com IA
================================================================================

1. VISÃO GERAL E FILOSOFIA DE DESIGN
--------------------------------------------------------------------------------
O diagrama unifilar interativo foi concebido para atender simultaneamente a dois
requisitos fundamentais:
  a) Software CAD Gráfico: Manipulação vetorial fluida, sistema de coordenadas infinito,
     zoom centrado no cursor, pan, atração à grade (snap-to-grid), rotação de elementos
     e manobra interativa de chaves/disjuntores.
  b) Engenharia de Sistemas Elétricos de Potência: Cada elemento visual reflete
     diretamente nós (barras) e ramos (linhas/transformadores) acoplados às equações de rede
     (Matriz Admitância Ybus, equações de fluxo de potência Newton-Raphson e curto-circuito).

A implementação utiliza HTML5 Canvas 2D nativo e JavaScript Modular puro (ES6+),
com zero dependências externas e zero etapas de compilação/build.


2. ARQUITETURA DE MÓDULOS E DIVISÃO DE RESPONSABILIDADES
--------------------------------------------------------------------------------
A estrutura é estritamente desacoplada em quatro camadas:

  +-----------------------------------------------------------------------+
  |  Camada de Interação (Canvas.js): Viewport, Câmera, Eventos, Ferramentas |
  +-----------------------------------------------------------------------+
                                     |
  +-----------------------------------------------------------------------+
  |  Camada de Apresentação (Renderer.js): Símbolos IEEE/IEC, Grid, Estilos|
  +-----------------------------------------------------------------------+
                                     |
  +-----------------------------------------------------------------------+
  |  Camada de Dados & Topologia (Model.js): Repositório de elementos e rede|
  +-----------------------------------------------------------------------+
                                     |
  +-----------------------------------------------------------------------+
  |  Camada de Elementos (Element.js e classes derivadas em /elements/)   |
  +-----------------------------------------------------------------------+

Arquivos centrais:
  * web/js/cad/Canvas.js     -> Gerenciador de viewport, mouse/teclado, seleção e wiring.
  * web/js/cad/Renderer.js   -> Motor de desenho do CanvasRenderingContext2D.
  * web/js/core/Model.js     -> Estado global da rede elétrica e gerenciador de IDs.
  * web/js/elements/         -> Bus.js, Line.js, Transformer.js, Generator.js,
                                Load.js, Shunt.js, TextLabel.js.


3. SISTEMA DE COORDENADAS, CÂMERA E VIEWPORT
--------------------------------------------------------------------------------
O sistema adota dois espaços de coordenadas distintos:
  * Coordenadas de Tela (Screen Space - sx, sy): Pixels relativos ao elemento HTML <canvas>.
  * Coordenadas de Mundo (World Space - wx, wy): Plano cartesiano contínuo onde os elementos
    elétricos realmente existem.

3.1 Estrutura da Câmera:
  camera = {
      x: 100,      // Deslocamento horizontal do mundo em pixels de tela
      y: 100,      // Deslocamento vertical do mundo em pixels de tela
      scale: 1.0   // Nível de zoom (fator de escala linear, ex: 0.2 a 4.0)
  }

3.2 Transformações Matemáticas:
  * Tela para Mundo:
      wx = (sx - camera.x) / camera.scale
      wy = (sy - camera.y) / camera.scale

  * Mundo para Tela:
      sx = wx * camera.scale + camera.x
      sy = wy * camera.scale + camera.y

3.3 Suporte a Alta Resolução (DPI / Retina Display):
  No evento de resize do canvas:
      dpr = window.devicePixelRatio || 1;
      canvas.width = rect.width * dpr;
      canvas.height = rect.height * dpr;
      ctx.resetTransform();
      ctx.scale(dpr, dpr);

3.4 Zoom Centrado no Cursor do Mouse:
  Garante que o ponto sob o cursor permaneça exatamente na mesma posição de tela durante o zoom:
      zoomFactor = deltaY < 0 ? 1.15 : 0.85;
      newScale = Math.max(0.2, Math.min(4.0, camera.scale * zoomFactor));
      camera.x = mouseX - (mouseX - camera.x) * (newScale / camera.scale);
      camera.y = mouseY - (mouseY - camera.y) * (newScale / camera.scale);
      camera.scale = newScale;

3.5 Pan (Navegação):
  Ativado ao segurar o botão do meio do mouse (button === 1) ou Barra de Espaço + Botão Esquerdo:
      camera.x += sx - dragStart.x;
      camera.y += sy - dragStart.y;
      dragStart = { x: sx, y: sy };

3.6 Grade Infinita Adaptativa (Grid):
  A grade é desenhada iterando apenas a área visível da tela transformada para o mundo:
      startX = Math.floor(-camera.x / camera.scale / gridSize) * gridSize;
      endX = startX + (canvasWidth / camera.scale) + gridSize * 2;
      startY = Math.floor(-camera.y / camera.scale / gridSize) * gridSize;
      endY = startY + (canvasHeight / camera.scale) + gridSize * 2;
  A cada 5 linhas da grade, desenha-se uma linha mestra (gridMajor) com tonalidade mais destacada.


4. MODELO ORIENTADO A OBJETOS DOS ELEMENTOS ELÉTRICOS
--------------------------------------------------------------------------------
4.1 Classe Base (Element.js):
  Propriedades obrigatórias:
    * id: Identificador inteiro único.
    * type: String ('Bus', 'Line', 'Transformer', 'Generator', 'Load', 'Shunt', 'TextLabel').
    * x, y: Posição central de referência no mundo.
    * width, height: Dimensões da caixa delimitadora base.
    * angle: Orientação angular (0, 90, 180, 270 graus).
    * selected: Booleano de seleção visual.
    * hovered: Booleano de foco do cursor.
    * isOnline: Booleano SCADA de status de operação (true = ligado, false = desligado).
    * parentBuses: Array de referências a objetos Bus.
    * results: Objeto contendo grandezas calculadas pelas simulações.

  Métodos da Classe Base:
    * getBounds(): Retorna { x, y, width, height } no mundo.
    * containsPoint(px, py): Retorna true se px, py estiver dentro de getBounds().
    * intersectsBox(x1, y1, x2, y2): Testa interseção de AABB com caixa de seleção.
    * move(dx, dy): Translada (x, y) e eventuais pontos em pointList.
    * rotate(): Incrementa angle em 90 graus módulo 360.
    * snapToGrid(gridSize): Arredonda x e y para o múltiplo mais próximo de gridSize.

4.2 Barra Elétrica (Bus.js):
  * Geometria: Barra retangular dimensionada (largura padrão 120px, altura 8px).
  * Orientação: Se angle for 90° ou 270°, inverte largura e altura (barra vertical).
  * Conexão Dinâmica de Ramos (getClosestPointOnBar):
      Dado qualquer ponto externo (px, py) de uma linha ou gerador, a barra calcula
      o ponto de conexão exato ao longo de seu eixo:
      - Barra horizontal: x = clamp(px, bounds.x, bounds.x + bounds.width), y = this.y
      - Barra vertical:   x = this.x, y = clamp(py, bounds.y, bounds.y + bounds.height)
  * Cores por Nível de Tensão:
      O método getBusColor(nominalVoltage) mapeia a tensão nominal (ex: 500kV = azul,
      230kV = vermelho, 138kV = verde, 69kV = roxo, 13.8kV = ciano) com tolerância de 15%.

4.3 Linha de Transmissão (Line.js):
  * Topologia: Referências a fromBus e toBus.
  * pointList: Array de pontos [{x, y}, ...] definindo a rota da linha.
  * Se pointList não possuir pontos intermediários, calcula automaticamente os terminais:
      p1 = fromBus.getClosestPointOnBar(toBus.x, toBus.y);
      p2 = toBus.getClosestPointOnBar(fromBus.x, fromBus.y);
  * Detecção de Clique (distToSegment):
      Distância euclidiana do ponto de clique ao segmento vetorial (v, w):
        l2 = |w - v|^2
        t = max(0, min(1, dot(p - v, w - v) / l2))
        projecao = v + t * (w - v)
        dist = |p - projecao|
      Se dist <= tolerancia (8 pixels), a linha é selecionada.

4.4 Transformador de Potência (Transformer.js):
  * Topologia: Conecta fromBus a toBus com símbolo de 2 enrolamentos no ponto médio ou livre.
  * Símbolo: Dois círculos sobrepostos de raio r = 14px com centros deslocados em d = 10px.
  * Suporte a OLTC (Comutador de Tapes sob Carga):
      Se hasTapChanger === true, desenha uma seta diagonal transpassando os enrolamentos.

4.5 Gerador (Generator.js), Carga (Load.js) e Shunt (Shunt.js):
  * Possuem referência a parentBus.
  * O símbolo pode orbitar ou rotacionar em torno da barra (angle = 0°, 90°, 180°, 270°).
  * Um condutor conecta o símbolo ao ponto mais próximo da barra pai.
  * Gerador: Círculo de raio 16px com curva Bezier representando uma senoide (~).
  * Carga: Linha com triângulo apontando para baixo (seta de demanda).
  * Shunt: Placas paralelas com traço de terra (Capacitor) ou espiras (Indutor).


5. SISTEMA SCADA DE DISJUNTORES (SWITCH BOXES)
--------------------------------------------------------------------------------
Um dos maiores diferenciais técnicos do sistema é a operação de disjuntores em tempo real:

5.1 Interface getSwitchBoxes():
  Presente em Line, Transformer, Generator e Load. Retorna as caixas dos disjuntores:
    [
      { x: boxX, y: boxY, width: 10, height: 10, terminal: 0, element: this },
      ...
    ]
  Cálculo da posição ao longo do segmento:
    Vetor unitário u = (p1 - p0) / |p1 - p0|
    Posição do disjuntor = p0 + u * min(15, |p1 - p0| / 2)

5.2 Interatividade e Manobra:
  1. No mousedown, a função hitTestBreaker(wx, wy) é testada antes da seleção de elementos.
  2. Ao clicar no disjuntor:
       el.isOnline = !el.isOnline;
  3. Se el.isOnline === false:
       - O elemento é desenhado em cinza (#64748b).
       - Os fluxos calculados de potência e corrente são zerados imediatamente.
       - Na simulação, o elemento é automaticamente excluído da matriz admitância Ybus.
  4. Renderização do Disjuntor:
       - Ligado / Fechado (Online): Preenchimento verde SCADA (#22c55e).
       - Desligado / Aberto (Offline): Preenchimento vermelho (#ef4444) com traço diagonal branco.
       - Efeito de hover: Glow/sombra radiante em torno da caixa.


6. GERENCIAMENTO DE RÓTULOS (TEXT LABELS)
--------------------------------------------------------------------------------
Os nomes e valores numéricos NÃO são desenhados de forma fixa nas barras ou linhas:
  * Cada texto é uma instância independente de TextLabel (herda de Element).
  * Tipos de dados (LabelDataType):
      - DATA_NAME: Nome do elemento pai.
      - DATA_VOLTAGE: Tensão calculada (kV ou p.u.).
      - DATA_ANGLE: Ângulo fasorial em graus (°).
      - DATA_PF_ACTIVE / DATA_PF_REACTIVE: Fluxo no ramo (MW / Mvar).
      - DATA_PF_LOSSES: Perdas ativas (MW / p.u.).
      - DATA_SC_CURRENT / DATA_SC_VOLTAGE: Corrente e tensão de curto-circuito.
  * Mobilidade e Amarração Relativa:
      - O usuário pode arrastar qualquer rótulo individualmente para desobstruir o desenho.
      - Ao arrastar ou alinhar à grade o elemento pai (ex: Barra), todos os rótulos filhos
        (lbl.parentElement === item) se movem solidariamente somando o mesmo dx, dy.
      - Renderização: Caixa arredondada tipo pílula com fundo semitransparente, evitando
        conflitos de legibilidade com a grade de fundo.


7. FLUXO DE CRIAÇÃO E FERRAMENTAS (WIRING & CAD TOOLS)
--------------------------------------------------------------------------------
A máquina de estados de interação (Canvas.activeTool) opera nos seguintes modos:

7.1 Inserção de Barras ('bus'):
  * Clique no mundo -> cria Bus(snappedX, snappedY) e instancia automaticamente um
    TextLabel filho do tipo DATA_NAME posicionado ligeiramente acima (y - 18).
  * Retorna a ferramenta para 'select'.

7.2 Inserção de Ramos - Fiação Elétrica ('line' ou 'transformer'):
  1. Primeiro clique: Busca barra no ponto (hitTestBus). Se encontrada, define
     wiringStartBus = bus.
  2. Movimento do mouse: Desenha linha pontilhada de pré-visualização (preview)
     entre wiringStartBus e a posição atual do cursor.
  3. Segundo clique: Busca barra destino (hitTestBus). Se for diferente de wiringStartBus:
     - Instancia Line(busA, busB) ou Transformer(busA, busB).
     - Calcula pontos de conexão ortogonais via getClosestPointOnBar.
     - Limpa wiringStartBus e retorna para 'select'.

7.3 Inserção de Cargas e Geradores ('load', 'generator', 'capacitor', 'inductor'):
  * Clique sobre ou próximo a uma barra: O elemento é criado vinculado àquela barra pai
    com a conexão estabelecida automaticamente.


8. SELEÇÃO, MOVIMENTAÇÃO E ATALHOS DE TECLADO
--------------------------------------------------------------------------------
  * Clique Simples: Seleciona o elemento sob o cursor e desmarca os demais.
  * Shift / Ctrl + Clique: Adiciona ou remove o elemento da seleção múltipla.
  * Clique em Área Vazia + Arraste: Inicia caixa de seleção retangular (marquee).
    Todos os elementos que intersectam a caixa são adicionados à seleção ao soltar o mouse.
  * Tecla 'R': Rotaciona 90° todos os elementos selecionados.
  * Tecla 'Delete' ou 'Backspace': Remove os elementos selecionados do Model,
    desconectando automaticamente ramos vinculados a barras deletadas.
  * Snap-to-Grid: Ao soltar elementos arrastados, ajusta a posição para o múltiplo
    da grade (gridSize = 20px). Para rótulos avulsos, utiliza snap fino (5px).


9. VISUALIZAÇÃO DE RESULTADOS ELÉTRICOS NA TELA
--------------------------------------------------------------------------------
Após a resolução do Fluxo de Potência ou Curto-Circuito:
  * Setas de Fluxo de Potência Ativa (P):
      Desenhadas no centro geométrico da linha de transmissão.
      A seta é rotacionada pelo ângulo do segmento e aponta no sentido do fluxo (1->2 ou 2->1).
      Preenchimento verde vibrante (#22c55e).
  * Setas de Contribuição de Falta (Curto-Circuito):
      Setas laranjas (#f59e0b) indicando o sentido de escoamento da corrente de falta (kA).
  * Badge de Falta na Barra:
      Se a barra estiver sob falta (hasFault === true) ou houver corrente calculada,
      uma caixa luminosa com brilho vermelho (glow) exibe: "⚡ Falta: X.XX kA".


10. GUIA PASSO A PASSO PARA REPRODUÇÃO EM OUTRO SISTEMA POR UMA IA
--------------------------------------------------------------------------------
Para reproduzir integralmente este diagrama unifilar CAD em outro projeto, execute
a seguinte sequência de implementação:

PASSO 1: Estrutura HTML e Canvas
  - Crie um contêiner CSS flex/grid ocupando 100% da viewport e insira a tag <canvas>.
  - Instancie a classe de Câmera e registre os cálculos de transformação
    screenToWorld e worldToScreen.

PASSO 2: Classe Base de Elemento
  - Crie a classe Element com (x, y, width, height, angle, isOnline, results).
  - Implemente containsPoint e intersectsBox para detecção de colisão baseada em AABB.

PASSO 3: Classes Específicas de Domínio Elétrico
  - Bus: Implemente getBounds com suporte a ângulo (0° horizontal, 90° vertical)
    e o método getClosestPointOnBar(px, py) clampando a coordenada ao longo da haste.
  - Line: Implemente pointList, containsPoint via distToSegment (tolerância de 8px)
    e getSwitchBoxes() calculando caixas de 10x10px próximas às extremidades.
  - Transformer, Generator, Load, Shunt: Implemente símbolos geométricos normatizados
    e o método getSwitchBoxes().

PASSO 4: Sistema de Rótulos Independentes (TextLabel)
  - Crie a classe TextLabel herdando de Element.
  - No Model, implemente updateAllLabels() formatando unidades (kV, p.u., MW, Mvar).
  - No loop de arrasto, garanta que mover o elemento pai também translade os rótulos filhos.

PASSO 5: Motor de Desenho (Renderer)
  - Limpe o canvas e aplique ctx.translate(camera.x, camera.y) e ctx.scale(scale, scale).
  - Desenhe a grade iterando sobre o retângulo visível da câmera.
  - Desenhe os elementos na ordem estrita de camadas (Z-Index):
      1. Linhas de Transmissão
      2. Transformadores
      3. Barras
      4. Geradores, Cargas e Shunts
      5. Disjuntores (Switch Boxes)
      6. Setas de fluxo ativo e de curto-circuito
      7. Rótulos de Texto (TextLabel)

PASSO 6: Gestão de Eventos e Máquina de Estados (Canvas Controller)
  - Registre mousedown, mousemove, mouseup, wheel, dblclick, contextmenu e keydown.
  - Implemente o hit testing priorizando: Rótulos -> Disjuntores -> Elementos -> Linhas.
  - Implemente a lógica de fiação de dois cliques (wiringStartBus -> wiringCurrentPoint -> destBus).
  - Implemente o clique no disjuntor alternando isOnline e notificando o modelo de cálculo.

PASSO 7: Integração com Modelos Numéricos
  - Ao montar as matrizes elétricas (Ybus, Jacobiana), verifique sempre `if (element.isOnline !== false)`.
  - Após convergir a simulação numérica, popule `element.results` e chame `model.updateAllLabels()`
    seguido de `canvas.requestRender()`.
